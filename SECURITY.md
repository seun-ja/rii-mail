# Security Policy

## How to Report a Vulnerability

We take security seriously. If you discover a security vulnerability in RiiMail, please do not report it via a public issue or pull request. Instead, please report it privately.

### Contacting Us
You can reach out to the maintainers at:
- Seun: [hello@oluseun.dev](mailto:hello@oluseun.dev)

Please provide as much information as possible about the vulnerability, including:
- The type of vulnerability (e.g., XSS, SQL Injection, etc.).
- Steps to reproduce the issue.
- Any proof-of-concept (PoC) code or screenshots.

## Our Response Process
Once reported, we will acknowledge your report within 3 days and provide an estimated timeline for a fix. We aim to resolve security issues as quickly as possible. 

Once a fix is released, we may credit you in the release notes if you choose to remain anonymous.

Thank you for helping keep RiiMail secure!
